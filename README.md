# QR Cafe Ordering Demo

This workspace contains a polished front-end demo for a QR-based cafe ordering experience with:

- Customer ordering flow for a selected table
- Kitchen board with live status updates
- Admin tools for tables, menu items, categories, and QR codes
- Local persistence and demo access controls

## Quick start

1. Open the project folder in a browser preview or run a local static server.
2. Visit http://127.0.0.1:8000/ if you are using Python's built-in server.
3. Use the customer view to select a table and place an order.
4. Open the kitchen view with the code: kitchen123
5. Open the admin view with the code: admin123

## Demo flow

- Select a table from the customer screen.
- Add items to the cart and enter a customer name.
- Place the order and watch it appear on the kitchen board.
- Update the order status from the kitchen board.
- Create or edit tables, menu items, and categories in the admin view.
- Generate and print QR codes for each table.
